## 1. 领取免费服务器（约 10 分钟）

1. 打开 <https://free.aliyun.com>，用支付宝或手机号注册/登录阿里云，并完成**个人实名认证**。
2. 在试用中心搜索"云服务器 ECS"，选个人版免费试用。推荐配置：
   - 规格：**2 核 4G**（2G 内存装 PyTorch 偏紧张）
   - 镜像：**Ubuntu 22.04 64 位**
   - 地域：选离你近的，例如西南 1（成都）或华东
   - 公网 IP：勾选"分配公网 IPv4 地址"，带宽 1~5 Mbps 即可
   - 登录密码：自己设一个，记下来
3. 创建完成后，进入「云服务器 ECS 控制台 → 实例」，记下**公网 IP**。
4. 放行端口：点实例 → 「安全组」→「管理规则」→「入方向」→ 手动添加：协议 TCP，端口 **80**，授权对象 `0.0.0.0/0`。

## 2. 一键部署（约 15~25 分钟，主要是下载依赖）

在实例页面点「远程连接」→「通过 Workbench 远程连接」，用 root 和你设的密码登录，然后复制粘贴下面两行：

```bash
git clone https://github.com/wangshiyun72/unipredict.git /opt/unipredict
bash /opt/unipredict/deploy/install.sh
```

如果 `git clone` 卡住或失败（阿里云访问 GitHub 有时不稳定），改用加速地址：

```bash
git clone https://gh-proxy.com/https://github.com/wangshiyun72/unipredict.git /opt/unipredict
```

脚本会自动完成：安装 Python 环境（CPU 版 PyTorch）→ 安装依赖 → 生成配置 → 用 4 个模板训练演示模型并设为公开 → 注册系统服务（开机自启）。

结束时屏幕上会显示：

```
 网页地址：  http://你的公网IP/
 管理员：    admin / 随机密码（请登录后修改）
```

**把这个管理员密码记下来**，登录后在右上角修改。

## 3. 日常维护

| 操作 | 命令 |
|---|---|
| 查看运行状态 | `systemctl status unipredict` |
| 查看实时日志 | `journalctl -u unipredict -f` |
| 重启服务 | `systemctl restart unipredict` |
| 更新到 GitHub 最新代码 | `cd /opt/unipredict && git pull && bash deploy/install.sh` |
| 修改配置 | 编辑 `/opt/unipredict/backend/.env`，然后重启服务 |
| 忘记 admin 密码 | `cd /opt/unipredict/backend && ../venv/bin/python scripts/reset_password.py admin 新密码` |

## 4. 注意事项

- 服务器没有显卡，模型在 CPU 上训练和推理。TabPFN 的上下文默认限制在 1000 行，深度学习模型训练会比本机慢。演示用的数据规模没有问题。
- 免费试用到期前，阿里云会提醒续费或释放。结题后如果还想继续开放，可以转成低价的包年实例。
- 目前通过 IP 地址访问，不需要备案。如果以后要绑定域名，需要先做 ICP 备案。
