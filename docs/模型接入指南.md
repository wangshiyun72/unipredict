# 模型接入指南

平台上的所有模型都通过同一个**模型适配器（Model Adapter）**接口接入。训练、预测 API、可解释性和可视化这些功能只依赖这个接口，所以接入一个新模型时，平台的其他部分都不用改。

有两种接入方式：

| 方式 | 适合场景 | 能否在平台内训练 |
|---|---|---|
| A. 写适配器插件 | 新的算法或模型结构，希望在平台上用不同数据反复训练 | 能 |
| B. 导入已训练模型文件 | 别人或别的软件已经训练好的模型，只需要对外提供预测服务 | 不能（只能预测） |

---

## 方式 A：写一个适配器插件

在 `backend/app/core/adapters/plugins/` 下新建一个 `.py` 文件，重启后端后，新模型会自动出现在"模型训练"页面。可以参考同目录下的示例插件 `example_extra_trees.py`。

```python
from ..base import FAMILY_DEEP, ModelAdapter, register_adapter

@register_adapter
class MyModelAdapter(ModelAdapter):
    key = "my_model"                    # 唯一标识
    name = "我的模型"                    # 界面显示名
    family = FAMILY_DEEP                # universal / deep / lightweight
    description = "一句话说明"
    tasks = ("regression",)             # 支持的任务
    requires = ("torch",)               # 依赖的包，缺失时界面显示"未安装依赖"
    uses_gpu = True                     # True 时训练和推理会经过 GPU 并发锁
    param_spec = [                      # 前端会根据这里自动生成参数表单
        {"name": "lr", "label": "学习率", "type": "float", "default": 1e-3, "min": 1e-5, "max": 0.1},
    ]

    def fit(self, X, y):                # X 是已经自动归一化的 numpy 矩阵
        ...
        return self

    def predict(self, X):
        ...

    def predict_proba(self, X):         # 分类任务需要实现，回归任务可以不写
        ...
```

要点：

- 输入 `X` 已经过平台的自动预处理：缺失值填充、类别编码、归一化、SMILES 特征化都做好了。适配器只需要关心模型本身。
- 分类任务的 `y` 已经编码成 `0..K-1` 的整数，平台会自动映射回原始类别名。
- 模型对象会被 `joblib` 序列化保存。如果对象里有不能序列化的东西（比如 GPU 上的 PyTorch 模块），参考 `deep.py` 的写法：实现 `__getstate__`，只保存权重。

## 方式 B：导入已训练模型文件

在网页"模型仓库 → 接入外部模型"里上传文件，需要填写：

- **输入特征**：按模型训练时的列顺序，用英文逗号分隔
- **任务类型**和**预测目标名**
- **样例数据**（可选）：用来生成网页输入表单的默认值，以及单样本可解释性的基线

### ONNX（推荐）

ONNX 是跨框架的通用模型格式，加载时不会执行任意代码，比较安全。需要安装 `onnxruntime`。

PyTorch 导出：

```python
import torch
model.eval()
dummy = torch.randn(1, n_features)
torch.onnx.export(model, dummy, "model.onnx", input_names=["input"], output_names=["output"],
                  dynamic_axes={"input": {0: "batch"}, "output": {0: "batch"}})
```

scikit-learn 导出（需要 `pip install skl2onnx`）：

```python
from skl2onnx import to_onnx
onx = to_onnx(sk_model, X_train[:1].astype("float32"))
open("model.onnx", "wb").write(onx.SerializeToString())
```

### joblib / pickle

这种格式支持 scikit-learn 模型或 Pipeline。pickle 文件在加载时可以执行任意代码，所以**只有管理员能导入**，而且只能导入来源可信的文件。
