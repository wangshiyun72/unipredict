# 部署说明（Windows + RTX 5060 Ti 8GB）

> 🌐 在线平台：http://8.156.66.225/ ｜ 📖 接口文档：http://8.156.66.225/docs ｜ 💻 源代码：https://github.com/wangshiyun72/unipredict

整个平台跑在一台电脑上，这台电脑就是"服务器"。同一局域网（实验室 / 校园网）里的其他电脑、外部程序都可以通过网页或 REST API 访问它。

```
基于服务器端通用模型的可访问式深度学习预测服务设计/
├── backend/                 后端：FastAPI 预测服务
│   ├── app/
│   │   ├── core/            算法核心：自动归一化、模型适配器、可解释性、训练流程
│   │   │   └── adapters/    模型适配器（通用 / 深度 / 轻量 / 外部），plugins/ 放自定义模型
│   │   ├── routers/         REST API 路由
│   │   ├── services/        数据集、数据模板、模型仓库、训练服务
│   │   ├── concurrency.py   并发访问控制（限流 + 并发闸门）
│   │   ├── tasks.py         训练任务队列
│   │   └── main.py          服务入口
│   ├── scripts/             环境检查、模板数据准备、压测、API 调用示例
│   └── storage/             运行时自动生成：数据库、数据集、模型文件（不要手动改）
├── frontend/                前端：Vue3 + Element Plus + ECharts
├── docs/                    文档
└── *.bat                    一键安装 / 启动脚本
```

## 第 1 步：安装 Node.js（前端需要，只装一次）

1. 打开 <https://npmmirror.com/mirrors/node/>，进入最新的 `v22.x.x/` 目录，下载 `node-v22.x.x-x64.msi`
2. 双击安装，一路"下一步"即可
3. 打开新的 cmd 窗口，输入 `node -v`，能看到版本号就成功了

## 第 2 步：安装后端环境（只装一次）

在开始菜单打开 **Anaconda Prompt**，进入项目文件夹，运行：

```bat
cd /d "%USERPROFILE%\Desktop\基于服务器端通用模型的可访问式深度学习预测服务设计"
setup_backend.bat
```

脚本会依次完成：创建 `unipredict` 环境（Python 3.11）→ 设置清华 pip 镜像 → 安装核心依赖 → 安装 CUDA 12.8 版 PyTorch → 安装可选依赖 → 环境检查 → 准备数据模板。

**注意事项**

- **RTX 50 系显卡必须用 CUDA 12.8（cu128）版本的 PyTorch**，旧版本 torch 不认识这张卡。环境检查里显示 `CUDA 可用：True` 和 `sm_120` 就对了。
- PyTorch 官方源下载慢的话，可以改用阿里云镜像：
  `pip install torch -f https://mirrors.aliyun.com/pytorch-wheels/cu128/`
  装完后运行 `python backend\scripts\check_env.py`，确认显示 `CUDA 可用：True`。如果是 False，说明装成了 CPU 版，需要换回官方源多试几次。
- 必须**先装 CUDA 版 torch，再装 tabpfn**，否则 tabpfn 会自动装一个 CPU 版 torch。如果顺序装反了，重新执行一次第 4 步的 torch 安装命令即可。
- RDKit、XGBoost 等可选依赖如果装失败，不影响平台运行，对应的模型或功能会在界面上显示"未安装依赖"。

## 第 3 步：安装前端依赖（只装一次）

双击 `setup_frontend.bat`（脚本会自动把 npm 源设为国内镜像 npmmirror）。

## 第 4 步：启动

1. 双击 `start_backend.bat`。看到 `Uvicorn running on http://0.0.0.0:8000` 就说明启动成功。
2. 双击 `start_frontend.bat`，然后浏览器打开 <http://localhost:5173>
3. 用管理员账号 `admin` / `admin123` 登录，**登录后先在右上角改密码**

接口文档地址：<http://localhost:8000/docs>

## 第 5 步（演示 / 正式使用）：单端口部署

双击 `build_and_deploy.bat`。它会先把前端打包成静态网页，再由后端直接提供，这样网页和 API 都在 8000 端口，只需要开一个窗口。

- 本机访问：<http://localhost:8000>
- 局域网内其他电脑访问：`http://本机IP:8000`
  - 查本机 IP：cmd 里运行 `ipconfig`，看"IPv4 地址"
  - 允许其他电脑访问：用**管理员身份**打开 cmd，执行
    `netsh advfirewall firewall add rule name="UniPredict" dir=in action=allow protocol=TCP localport=8000`

## TabPFN 通用模型说明

- 第一次用 TabPFN 训练时，会自动下载模型权重（几十 MB）。平台默认通过国内镜像 `https://hf-mirror.com` 下载，可以在 `backend/.env` 里用 `HF_ENDPOINT` 修改。
- 默认使用 TabPFN-2 权重：开源许可，学术使用不需要申请 token。
- 8GB 显存下，TabPFN 的训练上下文默认最多 3000 行（`TABPFN_MAX_TRAIN_ROWS`）；超过时会随机抽样。

## 配置项（backend/.env，可选）

在 `backend` 目录下新建 `.env` 文件，每行写一个 `KEY=VALUE`。不写就用默认值。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| PORT | 8000 | 服务端口 |
| DEFAULT_ADMIN_PASSWORD | admin123 | 初始管理员密码（仅在第一次启动、数据库为空时生效） |
| ALLOW_REGISTER | true | 是否允许自助注册 |
| PREDICT_CONCURRENCY | 8 | 同时执行的预测请求上限 |
| PREDICT_QUEUE_TIMEOUT | 15 | 预测请求最长排队秒数，超时返回 503 |
| GPU_CONCURRENCY | 2 | 同时使用 GPU 的训练/推理数 |
| TRAIN_WORKERS | 2 | 同时运行的训练任务数 |
| MAX_JOBS_PER_USER | 2 | 每个用户同时排队+运行的训练任务数 |
| RATE_LIMIT_USER_PER_MIN | 300 | 网页用户每分钟请求上限 |
| RATE_LIMIT_KEY_PER_MIN | 60 | 新建 API Key 的默认每分钟上限 |
| TABPFN_MAX_TRAIN_ROWS | 3000 | TabPFN 上下文最大行数 |
| HF_ENDPOINT | https://hf-mirror.com | HuggingFace 镜像 |
| DEVICE | auto | auto / cuda / cpu |

> 后端必须以**单进程**运行（`start_backend.bat` 已经这样设置）。限流计数、并发闸门和任务队列都保存在进程内存里；并发能力由异步 I/O 加线程池提供。

## 并发压测（为结题报告准备数据）

1. 先启动后端，并至少训练好一个模型（例如在"数据模板"页面对「反应条件→产物收率预测」点"一键演示训练"）
2. 双击 `run_benchmark.bat`，输入模型 ID
3. 结果保存在 `backend/benchmark_results/`：CSV 表格、性能曲线 PNG、Markdown 汇总
4. 压测时打开网页的"运行监控"页面，可以实时看到并发、排队、限流的情况，适合截图

## 常见问题

| 现象 | 解决办法 |
|---|---|
| `conda` 不是内部或外部命令 | 在开始菜单里打开"Anaconda Prompt"再运行脚本 |
| `CondaToSNonInteractiveError: Terms of Service have not been accepted` | 新版脚本已改用清华 conda-forge 镜像建环境，不再走 Anaconda 默认频道。重新运行 `setup_backend.bat` 即可 |
| 网页打开是空白，或接口报 502 | 后端没启动，先运行 `start_backend.bat` |
| 训练时某个模型显示"未安装依赖" | 用 `pip install 包名` 装上后重启后端 |
| TabPFN 下载权重失败 | 检查网络；在 `.env` 里确认 `HF_ENDPOINT=https://hf-mirror.com` |
| `CUDA 可用：False` | torch 不是 cu128 版本，重新执行第 2 步里的 torch 安装命令 |
| 想恢复成全新状态 | 停止后端，删除 `backend/storage/` 文件夹，再重新启动 |
